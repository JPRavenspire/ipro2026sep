# Arithmatic Operators

Here is a list of arithmatic/numeric operators in Python.

| Operator            | Symbol |
| ------------------- | ------ |
| Addition            | `+`    |
| Subtraction         | `-`    |
| Multiplication      | `*`    |
| Division            | `/`    |
| Exponentiation      | `**`   |
| Floor Division      | `//`   |
| Modulus (remainder) | `%`    |

```python
print(7 + 9)
```
