# Build your own (portfolio) website

Your website should contain at least 3 pages:

1. project
2. about me
3. resume/cv

Each page should have a header, main and footer. Each header should contain a < nav > element that links to each other page.

This website is something you should strongly consider to continue developing if you're serious about getting a job in webdevelopment. Even with programming in general it will be a plus if employers see you made your own website.

If you decide to use this as a portfolio website, it doesn't just host your portfolio, the website itself is part of your portfolio! Most importantly, it's your own website. So give it your own spin and flair! 

You can use just HTML & CSS, or add extra features with Javascript, Python, and/or Flask.
Good luck and have fun!
